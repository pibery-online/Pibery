# 🛍️ Pibery - E-commerce Web Application

Pibery একটি আধুনিক এবং দ্রুত ই-কমার্স ওয়েবসাইট যা Flask (Python) এবং PostgreSQL (Supabase) দিয়ে তৈরি।

## 🚀 ফিচারসমূহ
- 🛒 প্রোডাক্ট কার্ট ও অর্ডার প্রসেসিং সিস্টেম
- 👤 ইউজার ও এডমিন প্যানেল
- 📲 টেলিগ্রাম বোট ইন্টিগ্রেশন (নতুন অর্ডারের সাথে সাথে মেসেজ নোটিফিকেশন)
- 🗄️ Supabase Cloud Database সংযোগ
- ☁️ Render Web Service Deploy-ready

## 🛠️ প্রযুক্তি (Tech Stack)
- **Backend:** Python (Flask, SQLAlchemy, Flask-Login)
- **Frontend:** HTML5, CSS3, Bootstrap 5, Jinja2
- **Database:** PostgreSQL (Supabase)
- **Hosting:** Render
